# Мова програмування РАВЛИК — публічна довідка

РАВЛИК — навчальна текстова мова для дітей. Програма керує персонажем на полотні: Равлик рухається, повертається й малює. Основний редактор доступний на [ravlyk.org](https://ravlyk.org/), а розгорнутий посібник — на [ravlyk.org/manual](https://ravlyk.org/manual).

Ця сторінка призначена і для людей, і для програмних агентів, які пояснюють РАВЛИК або створюють приклади. Використовуйте тільки описаний нижче синтаксис.

## Загальні правила

- Одна команда зазвичай записується в окремому рядку.
- Коментар починається з `//` і триває до кінця рядка. Запис через `#` підтримується для сумісності.
- Блок команд записується в круглих дужках: `(...)`.
- Назви команд і змінних не залежать від регістру.
- Числові вирази підтримують `+`, `-`, `*`, `/`, `%` і групування дужками.
- Код має бути скінченним і підпорядковується runtime-лімітам, щоб не зависав браузер.

## Мінімальний приклад

```text
колір синій
повторити 4 (
  вперед 100
  праворуч 90
)
```

Програма малює синій квадрат.

## Рух і поворот

| Українська команда | Англійський псевдонім | Значення |
| --- | --- | --- |
| `вперед число` | `forward number` | Рух уперед |
| `назад число` | `backward number` | Рух назад |
| `праворуч кут` | `right angle` | Поворот праворуч у градусах |
| `ліворуч кут` | `left angle` | Поворот ліворуч у градусах |
| `перейти x y` | `goto x y` | Перехід у координати |
| `додому` | `home` | Повернення в початкову позицію без малювання |

Для координат можна написати `перейти в 100 -50` або `перейти 100, -50`. Варіант із комою дозволяє повні арифметичні вирази в обох координатах.

## Полотно й олівець

```text
колір червоний
фон білий
товщина 5
підняти
опустити
очистити
сховати
показати
вишиванка
звичайний
```

Англійські псевдоніми: `color`, `background`, `thickness`, `penup`, `pendown`, `clear`, `hide`, `show`, `vyshyvanka`, `zvychainyi`.

Аргумент `товщина` має бути цілим числом від `1` до `50`.

`колір випадково` і `фон випадково` вибирають випадковий дозволений колір. `перейти випадково` вибирає безпечну точку на полотні.

## Пауза

```text
чекати 1
пауза 0.5
wait 2
```

Аргумент задається в секундах і має бути від `0` до `60`. Пауза заборонена всередині блоку `грати`.

## Змінні та вирази

Змінну створюють один раз через `створити`, а потім змінюють звичайним присвоєнням:

```text
створити сторона = 80
вперед сторона
сторона = сторона + 20
вперед сторона
```

Англійський псевдонім `створити` — `create`.

Повторне `створити сторона = ...` є помилкою. Зарезервовані слова не можна використовувати як назви змінних, функцій або параметрів.

Підтримувані числові функції:

```text
модуль(-50)          // 50
корінь(100)          // 10
випадково(10, 100)   // число від 10 до 100
```

Англійські псевдоніми: `abs`, `sqrt`, `random`.

Спеціальний вираз `кут` повертає поточний напрямок Равлика в діапазоні від `0` включно до `360` невключно. Після `праворуч 90` значення `кут` дорівнює `90`.

## Цикл із відомою кількістю повторів

```text
повторити 6 (
  вперед 60
  праворуч 60
)
```

Псевдоніми: `повтори`, `repeat`. Кількість повторів має бути цілим числом від `0` до `500`.

## Умови

```text
якщо сторона > 50 (
  колір зелений
) інакше (
  колір жовтий
)
```

Псевдоніми: `if`, `else`. Оператори порівняння: `=`, `!=`, `<`, `>`, `<=`, `>=`.

Спеціальні умови:

```text
якщо край (
  праворуч 180
)

якщо клавіша "ArrowUp" (
  вперед 5
)

якщо не край (
  вперед 10
)
```

Псевдоніми: `edge`, `key`; заперечення — `не`.

## Умовний цикл і вихід із циклу

```text
створити x = 0
поки x < 10 (
  вперед 10
  x = x + 1
)
```

Псевдонім `поки` — `while`.

Команда `стоп` або `break` виходить лише з найближчого циклу:

```text
повторити 100 (
  якщо край (
    стоп
  )
  вперед 10
)
```

`стоп` поза циклом є помилкою.

## Функції

```text
створити квадрат(сторона) (
  повторити 4 (
    вперед сторона
    праворуч 90
  )
)

квадрат(100)
```

Кількість аргументів під час виклику має точно збігатися з кількістю параметрів. Не можна створювати дві функції з однаковою назвою або залишати тіло функції порожнім. Повернення значень через `return` не підтримується.

## Ігровий режим

```text
створити швидкість = 5

грати (
  якщо клавіша "ArrowUp" (
    вперед швидкість
  )
  якщо клавіша "ArrowRight" (
    праворуч 5
  )
)
```

Псевдонім `грати` — `game`.

У програмі може бути не більше одного блоку `грати`, і він має бути на верхньому рівні. Якщо блок `грати` присутній, поза ним дозволені тільки створення змінних та оголошення функцій.

## Основні обмеження

- довжина програми: до 10 000 символів;
- вкладеність parser-блоків: до 20 рівнів;
- повторення одного циклу `повторити`: до 500;
- розмір AST: до 5 000 вузлів;
- тривалість одного `чекати`: до 60 секунд;
- нескінченні або надто довгі обчислення зупиняються дружньою помилкою.

## Чого в мові немає

- довільного JavaScript-коду, `eval` або доступу до DOM;
- мережевих запитів із дитячої програми;
- класів, масивів і об’єктів;
- повернення значення з функції;
- серверного виконання чи хмарного збереження програми.
