Коротко

РАВЛИК — статичний освітній сайт без облікових записів, реклами, backend і хмарного збереження дитячих програм.

Код із редактора виконується локально у браузері та не надсилається автору сайту.

Що зберігається на пристрої

  • Налаштування доступності та координатної сітки можуть зберігатися у localStorage.
  • Окремі ігри можуть тимчасово пам’ятати прогрес у sessionStorage до закриття вкладки.
  • РАВЛИК не використовує cookies для власних функцій.

Код дитини та share-посилання

Звичайний код у редакторі залишається у поточній вкладці. Якщо користувач сам створює share-посилання, код записується у фрагмент URL після #code=.

Фрагмент URL не входить до звичайного HTTP-запиту, але кожен, кому передано таке посилання, зможе прочитати код. Тому не варто додавати до програми ім’я, адресу чи інші особисті відомості.

Аналітика відвідувань

Сайт використовує Cloudflare Web Analytics, щоб бачити узагальнену кількість відвідувань і технічні показники завантаження сторінок.

За офіційним описом Cloudflare, Web Analytics не збирає персональні дані відвідувачів. Сервіс не використовує cookies, localStorage або fingerprinting для аналітики.

РАВЛИК не використовує Google Analytics, рекламні профілі чи персоналізовану рекламу.

Технічні постачальники

Сайт розміщено на GitHub Pages, а аналітичний beacon надає Cloudflare. Під час мережевих запитів ці постачальники можуть обробляти стандартні технічні дані відповідно до власних політик.

  • Заява GitHub про приватність.
  • Політика приватності Cloudflare.

Що може зробити користувач

  • Очистити дані сайту в налаштуваннях браузера, щоб скинути локальні налаштування.
  • Заблокувати analytics-скрипти засобами браузера або розширенням захисту приватності.
  • Не створювати й не передавати share-посилання, якщо код не має бути доступним іншим.
