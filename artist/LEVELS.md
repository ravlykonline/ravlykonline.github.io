# LEVELS.md — рівні Равлика Художника

Файл `js/data/lessons.js` містить 20 рівнів у 4 розділах. Один рушій (turtle), перевірка за фігурою, еталон — це `solution` (дерево блоків); пунктир і «найкраще: N блоків» будуються з нього.

## Схема рівня

```js
{
  id: 'lesson-07',                 // lesson-NN, по порядку
  chapter: 'Повторення',           // назва розділу (рівні одного розділу йдуть підряд)
  title: 'Рівень 7: Квадрат циклом',
  instruction: '…',                // коротко, на «ти», без HTML; з розділу 2 — мета, а не список блоків
  intro: { icon, title, body, code? }, // лише там, де з’являється нова ідея; code — справжній синтаксис РАВЛИК
  start: { x, y, heading },        // кратні 50; вісь y вниз; heading 0 = вгору, 90 = праворуч
  pen: { color, width },           // колір — назва з data/colors.js
  showGrid: true | 'faint' | false,
  toolbox: ['step', 'repeat', …],  // типи блоків із data/blocks.js
  solution: [ … ],                 // дерево блоків (blk(...)); немає лише у вільних рівнів
  success: { mode: 'shape' | 'free', checkColor?, minSegments? },
  constraints?: { requireBlocks?: ['repeat'], requireNestedRepeat?: true, bestBlocks?: N },
  startBlocks?: [ … ],             // початкова програма (рівень «Знайди помилку»)
  successMessage, successTitle?, successButton?,
}
```

- `bestBlocks` за замовчуванням = кількість блоків у `solution`. Зірки: ≤ best — 3★, ≤ best+2 — 2★, інакше 1★.
- `startBlocks` отримують нові id при кожному завантаженні рівня (шаблон не мутується); скасування працює як зі звичайною програмою.
- Фігури лишаються в межах ±180 × ±130; старти вирівняні так, щоб фігура була приблизно по центру поля.
- Прогрес (пройдені рівні, найкращі зірки) тримається лише в пам’яті сесії, без `localStorage`.
- Навігація: точки згруповані за розділами, вільний перехід на будь-який рівень.

## Як додати або змінити рівень

1. Додай об’єкт у `lessons.js` на потрібне місце й перенумеруй `id` та заголовки (тест перевіряє послідовність).
2. Напиши `solution` — тести самі перевірять 3★, межі поля, «майже правильні» варіанти й код у справжньому парсері РАВЛИК.
3. Не давай в `intro` і `instruction` повну відповідь рівня (особливо кути): опиши мету, а не список блоків.
4. `npm --prefix artist test`, `npm run test:unit`, `npm run lint`.
