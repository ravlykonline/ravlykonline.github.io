# Равлик Художник

Навчальна гра для дітей: з блоків-«пазлів» як у Scratch складаєш програму, а Равлик малює фігуру за пунктиром. Вкладка **«Код»** показує справжній код мови [РАВЛИК](../README.md) — його можна скопіювати в головний редактор і отримати той самий малюнок.

Сторінка: `https://ravlyk.org/artist/` (поки не в `sitemap.xml` — окреме рішення власника). Код — у цій теці.

## Що вміє

- **Вітальний екран** для новачка: три дії та ілюстрація, на якій равлик один раз малює будиночок і зупиняється. За ввімкненого зменшення руху відразу видно готовий будиночок. Екран з’являється, якщо у вкладці немає прогресу, адреса без `?level=N` і «До першого рівня» ще не натискали.
- **21 рівень у 4 розділах**: «Перші кроки» (кроки й повороти), «Повторення» (цикл `повторити`, підняти/опустити олівець), «Числа і кути» (числа в блоках, кути 120°, 60°, 144°, майже коло), «Кольори і творчість» (колір, цикл у циклі, налагодження, вільне малювання). Перелік — у [`LEVELS.md`](LEVELS.md).
- **Перевірка за фігурою**, а не за кількістю ліній: неправильний кут чи зайва лінія не зараховуються; є підказки «подивись на пунктир». Зірки ★★★ залежать від кількості блоків.
- **Блоки як у Scratch**: пазли, поля-овали, випадний список кольорів, перетягування мишею, пальцем і пером, вільні стоси, скасування/повернення, меню «⋯» на блоці, повна клавіатурна альтернатива.
- **Керування**: Старт/Далі, Крок і Стоп під сценою. «Спочатку» і швидкість у меню сцени, очищення у меню програми. Під час виконання підсвічується поточний блок або рядок коду.
- **Код РАВЛИК**: підсвітка синтаксису, «Копіювати код», блок підготовки поля (`// Підготовка поля`) для точного збігу з головним редактором.
- **Адаптивність**: ПК (3 колонки), планшет, телефон (стрічка палітри, посилання «До сцени», «Рівень N / 21 ▾»), телефон набік (поле й програма поруч).
- **Доступність**: живий статус поля («Равлик у точці x, y, дивиться праворуч, олівець опущено»), текстовий опис пунктирної фігури, фокус-пастки в модалках, видимий фокус, контраст ≥ 4.5:1, `prefers-reduced-motion`.
- **Приватність**: без реєстрації, без backend, без `localStorage`; прогрес (пройдені рівні й зірки) і позначка «вітання бачили» — у sessionStorage вкладки, зникає після її закриття; код дитини не зберігається.

## Запуск

Сайт статичний. З кореня репозиторію:

```bash
node tests/e2e/server.js          # http://127.0.0.1:4173 (порт змінює RAVLYK_PREVIEW_PORT)
# відкрити /artist/index.html
```

Будь-який статичний сервер, що віддає корінь репозиторію, підійде: сторінка підтягує шрифт Nunito з `/assets/fonts/`.

## Тести

```bash
npm --prefix artist test     # модульні тести гри (core, goals, blocks, controls, levels, a11y)
npm run test:unit            # корінь; включає tests/artistCodegen.test.js — код гри проти справжнього парсера РАВЛИК
npm run lint                 # eslint js/ sw.js artist/js/
npm run check                # усе разом (+ перевірки документації, release-токена, precache)
```

Деталі — [`TESTING.md`](TESTING.md).

## Структура

```text
index.html           розмітка сторінки (одна SVG-поле, палітра, програма, вкладка «Код», модалки)
css/                 tokens.css (усі кольори/розміри), base, layout, components, blocks, responsive, accessibility
js/main.js           склейка: стан, події, цикл виконання
js/core/             чиста логіка без DOM: codegen, goals, workspace, blockTree, blockShape, ghost, describe, stars, state
js/domain/           turtle (модель черепахи), snail (трансформація й анімація кроку)
js/runtime/          runner (ліниві кроки по дереву блоків), stepper, stepController, execution-limits
js/data/             blocks, colors, lessons
js/state/            history (скасування/повернення), progressStore (прогрес у sessionStorage)
js/ui/               DOM: blockView, dragdrop, palette, workspaceView, canvas, popover, render, codeView, меню
js/utils/            focus-trap, sleep, sounds
tests/               art.*.test.js
legacy/              стара версія; не редагувати й не імпортувати
```

Докладніше — [`ARCHITECTURE.md`](ARCHITECTURE.md). Правила для розробників і агентів — [`AGENTS.md`](AGENTS.md). Плани й ідеї — [`TASKS.md`](TASKS.md).

## Реліз

Кореневий Service Worker кешує `/artist/js/*.js` cache-first. Після змін у `artist/` перед деплоєм підніміть release-токен кореня (`npm run release:sync-version -- YYYY-MM-DD-N`, див. [`../RELEASE_CHECKLIST.md`](../RELEASE_CHECKLIST.md)) і запустіть `npm run check`.
