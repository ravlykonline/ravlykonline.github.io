# AGENTS.md — інструкції для Codex, Claude Code та інших AI-агентів

Перед змінами прочитати цей файл, `README.md`, `ARCHITECTURE.md`, `LEVELS.md`, `TESTING.md`, `ACCESSIBILITY.md`, `SECURITY.md` і `TASKS.md`. Кореневі `AGENTS.md` і `LANGUAGE_SPEC.md` (розділи 5, 6, 9, 16) теж обов’язкові: гра генерує код мови РАВЛИК.

## 1. Що це

«Равлик Художник» (`/artist/`) — гра для дітей: з «пазлів-блоків» як у Scratch складаєш програму, Равлик малює фігуру з пунктиру. Вкладка «Код» показує **справжній код РАВЛИК**, який можна вставити в головний редактор і отримати той самий малюнок.

Стек: статичний сайт, HTML + CSS + JavaScript ES Modules, SVG. Без backend, без бандлерів, без залежностей, без CDN. Тести — `node` (без фреймворків).

## 2. Стан

Усі фази з `FINAL_PLAN.md` виконано (1 ядро, 2 равлик і поле, 3 блоки, 4 код і керування, 5 двадцять один рівень, 6 адаптивність, доступність, документація, реліз). Що лишилось — у `TASKS.md`. Не повертайтесь до вже закритого без відтвореної проблеми.

## 3. Жорсткі правила

1. **Один рушій (turtle).** Жодного grid-режиму, `mode` у рівнях немає. Сітка — лише підкладка поля (`showGrid`).
2. **Генерація коду — контракт.** Усе, що показує вкладка «Код», — валідний РАВЛИК (див. розділ 4). Тест `tests/artistCodegen.test.js` у корені проганяє розв’язок кожного рівня через справжній `RavlykParser` + `validateProgramAst` + `createAstRuntime` і порівнює відрізки з рушієм гри. Його не можна послаблювати чи пропускати.
3. **Без `localStorage`/cookies і без збереження коду дитини.** Прогрес (пройдені рівні й зірки) — у sessionStorage вкладки, зникає після її закриття; код дитини не зберігається (`state/progressStore.js`, за id рівня, у try/catch). «Інтро вже бачили», програми рівнів (щоб не губити роботу при перемиканні рівнів) і звук — лише в пам’яті сторінки (`core/state.js`). Не вмикайте автозбереження дитячих програм у будь-яке сховище.
4. **Нічого не копіювати з чужого коду без ліцензії.** Блоки, перетягування, форми «пазлів», CSS, SVG і тексти написані самостійно. Репозиторії без ліцензії (зокрема `robot-courier` з it-maysternia, що надихав дизайн) — лише джерело ідей: ні рядка коду, розмітки, CSS чи SVG звідти брати не можна. Те саме для будь-якого іншого коду без явної сумісної ліцензії. У PR/звіті вказуйте, звідки взято сторонній код і під якою ліцензією (шрифт Nunito — SIL OFL, файли з кореня сайту).
5. **DOM без `innerHTML` з даними.** Лише `createElement`/`createElementNS`/`textContent`/`setAttribute`. Жодного `eval`/`new Function`.
6. **Не чіпати `legacy/`** (не редагувати, не імпортувати).
7. **Нові npm-залежності, фреймворки, CDN — заборонені.**
8. **Дружні тексти дітям**: українською, на «ти», без стек-трейсів і англійських помилок.
9. **Логіка окремо від DOM.** `core/`, `domain/`, `runtime/`, `data/`, `state/` — чисті модулі без DOM. DOM — лише `ui/`, `main.js`, `utils/focus-trap.js`.
10. **Кольори — тільки токени** з `css/tokens.css` (у `blocks.css` hex заборонені тестом). Палітра — з головного сайту (`DESIGN_GUIDE.md` §3–4: #f0f8ff, #333, #4b0082, #6a5acd, #00796b, #ff6347; success/warning/danger/info), шапка й нижня панель світлі, градієнтів немає; шапка — один компактний ряд (≈56 px) без назв розділів.
11. **Не змінювати нічого поза `artist/`**, крім кореневого `tests/artistCodegen.test.js`, його рядка в `package.json` (`test:unit`) і релізного токена (`release-version.json` через `npm run release:sync-version -- YYYY-MM-DD-N`).

## 4. Контракт codegen

`buildProgramCode(lesson, workspace) → { setup: string[], body: string[], lineByBlockId: Map }`.

- **Лише валідний РАВЛИК**: `вперед N`, `назад N`, `праворуч N`, `ліворуч N`, `підняти`, `опустити`, `колір назва`, `товщина N`, `перейти в X Y`, цикл `повторити N (` … `)`. Заборонено: `коли запущено`, `разів {`, `рухатися(`, англійські команди. Hat-блок «коли ▶ натиснуто» в коді не з’являється.
- **Setup-блок** (`// Підготовка поля`) генерується завжди: `підняти`, `перейти в X Y`, `праворуч <heading>` (якщо heading ≠ 0), `опустити`, `товщина N`, `колір назва`. У РАВЛИК за замовчуванням товщина 1 і чорний колір, а в грі — інакше, тож стартовий стан завжди виписується явно. Далі коментар `// Твоя програма` і тіло.
- **Інверсія y**: у грі вісь y вниз, у `перейти в` РАВЛИК — вгору. Точка гри (x, y) → `перейти в x −y`. Покрито тестом.
- Вміст імен кольорів — лише з `data/colors.js` (звіряється з `COLOR_REGISTRY` кореня).
- Відступ 2 пробіли на рівень вкладеності. `lineByBlockId` потрібен для підсвітки поточного рядка під час виконання.
- Нова команда мови: оновити `LANGUAGE_SPEC.md` кореня (якщо чіпаєте мову), `data/blocks.js` (`code()`), `codegen.js`, `runtime/runner.js`, `core/describe.js` (опис), `LEVELS.md`/`ARCHITECTURE.md`, тести (включно з кореневим).

## 5. Блоки

Опис — `data/blocks.js` (`blockDefinitions`): тип, мітка-фраза як у Scratch (`text: [до поля, після поля]`), категорія (`move|turn|pen|color|repeat`), параметр (`number` з `min/max/step/quick` або `color`), `container` для C-блока, `code(block)`.

- Дані: дерево `{ id, type, n?, color?, blocks? }` (`core/blockTree.js`); робоча область = головний стос під hat + «вільні» стоси (не виконуються, напівпрозорі) — `core/workspace.js` (чисті функції: хвіст, вставка, найближча точка зчеплення, вільні стоси, межі параметрів).
- Вигляд: `ui/blockView.js` (контур-пазл з SVG-шляху за виміряним розміром — `core/blockShape.js`, текст і поля — справжній HTML), `ui/palette.js`, `ui/workspaceView.js`.
- Перетягування: `ui/dragdrop.js` — pointer events для миші, дотику й пера (поріг 6 px, «хвіст», магнітне зчеплення (радіус ≈44 px, гістерезис — `core/snap.js`) з позначкою вставки поверх полотна, автопрокрутка, кошик-палітра). `touch-action: none` — лише на `.blk`; у стрічці палітри на телефоні `.blk-palette { touch-action: pan-x }` (горизонталь гортає стрічку, вертикаль тягне блок). Клавіатура: Tab/↑↓/Delete/Enter/Esc.
- Числові поля: цифрова клавіатура, −/+ з автоповтором і швидкі кути 10/30/45/60/90/120 (144 навмисно немає — це відповідь рівня «Зірка»).
- Обмеження: `MAX_REPEAT_COUNT = 500`, вкладеність ≤ 3, ≤ 1000 розгорнутих дій (`runtime/execution-limits.js`).

## 6. Як додати рівень

1. `js/data/lessons.js`: об’єкт за схемою з `LEVELS.md`, на потрібне місце; перенумеруйте `id` і заголовки (`lesson-NN`, «Рівень N: …»).
2. **`solution` обов’язковий** (крім вільних рівнів `success.mode: 'free'`): це дерево блоків-еталон. Пунктир (ghost) і `bestBlocks` будуються з нього; ручних координат немає.
3. Старт і розміри кратні 50, фігура в межах ±180 × ±130. Інтро коротко пояснює нову ідею. Інструкція описує мету. Текст програми показує вкладка «Код».
4. Запустіть тести: вони перевіряють, що `solution` дає 3★, порожня програма не проходить, «майже правильні» варіанти (наприклад кут 90 замість 120) не проходять, код парситься справжнім парсером і дає ті самі відрізки.
5. Оновіть `LEVELS.md`. Перевірте рівень руками в браузері на 375 і 1280 px.

## 7. Адаптивність і доступність (контракт)

- ≥ 1024 px: «Палітра | Програма | Сцена»; 700–1023: зверху завдання й сцена, знизу редактор; < 700: завдання, сцена, палітра й програма. Вкладки «Блоки | Код» у шапці програми. Старт, Крок і Стоп під сценою. У короткому ландшафті сцена й редактор поруч. На 360–414 px горизонтального скролу сторінки немає.
- Шапка ≤ 900 px: «Рівень N / 21 ▾» відкриває список рівнів за розділами.
- Цілі натискання ≥ 44×44 на дотик (`pointer: coarse`).
- Статус поля — `aria-live` («Равлик у точці x, y, дивиться праворуч, олівець опущено», `core/describe.js`); опис пунктирної фігури текстом у `#ghost-desc`.
- Модалки: `role="dialog" aria-modal`, фокус-пастка, решта сторінки `inert`, Escape закриває, фокус повертається.
- Контраст тексту ≥ 4.5:1 (перевіряє `tests/art.a11y.test.js` за токенами), двоколірний `:focus-visible`, `prefers-reduced-motion` вимикає анімацію.

## 9. Реліз і кеш

Cloudflare Pages віддає файли з `Cache-Control: max-age=14400` (4 години) і ігнорує `_headers`, а кореневий Service Worker (`/sw.js`, scope `/`) кешує файли cache-first. Тому всі адреси гри версіоновані release-токеном: CSS і `js/main.js` в `index.html` мають `?v=<токен>`, а згенерована import map (між маркерами `generated:artist-importmap`) перенаправляє кожен модуль `artist/js/**` на `<модуль>?v=<токен>`. Генерує це `scripts/sync-artist-version.mjs` у складі `npm run release:sync-version -- YYYY-MM-DD-N`. Будь-яка зміна `artist/index.html`, `artist/js/**` чи `artist/css/**` вимагає нового токена — це перевіряє `npm run release:check-token` у CI. Import map не редагувати вручну; новий модуль потрапляє в неї після запуску скрипта (тест `tests/releaseVersion.test.js` впаде, якщо забути). `sitemap.xml` не чіпати (artist поки поза індексом — рішення власника).
