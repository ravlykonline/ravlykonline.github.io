# ACCESSIBILITY.md — доступність «Равлика Художника»

## Що реалізовано

- **Клавіатура**: усе, що робиться мишею чи пальцем, можна зробити з клавіатури. Палітра: Tab + Enter/Space додає блок (у вибраний цикл або в кінець). Блоки в програмі: Tab, ↑/↓ — переміщення, Delete — видалити, Enter на циклі — вставляти всередину, Esc — назовні, меню «⋯» (також Shift+F10/контекстне меню) з діями. Ctrl+Z/Y — скасувати/повернути, Ctrl+Enter — запустити.
- **Живий статус поля** (`#canvas-status`, `role="status" aria-live="polite"`): «Равлик у точці x, y, дивиться праворуч, олівець опущено» (`core/describe.js`; напрямки словами, вісь y вниз). Під час автозапуску читається лише підсумок.
- **Опис мети**: `#ghost-desc` (sr-only) у блоці завдання — послідовність ліній пунктиру словами або короткий підсумок для складних фігур.
- **Оголошення дій** (`#sr-announcer`): додано/видалено/переміщено блок, крок виконано, поле очищено, результат запуску.
- **Модалки** (успіх, інтро, підтвердження очищення): `role="dialog" aria-modal="true"`, фокус-пастка, решта сторінки `inert`, Escape закриває, фокус повертається на елемент, що відкрив.
- **Фокус**: двоколірний `:focus-visible` (жовте кільце + темна обвідка) — видно на світлому й темному тлі; на блоках — контур фігури.
- **Контраст**: текст ≥ 4.5:1, графіка (пунктир, фокус) ≥ 3:1; перевіряє `tests/art.a11y.test.js` за токенами `css/tokens.css`. Блоки — два варіанти (яскравий/пастельний), обидва ≥ 4.5:1.
- **Рух**: `prefers-reduced-motion` вимикає анімації; рушій показує лише кроки.
- **Дотик**: цілі ≥ 44×44 (`pointer: coarse`), перетягування не конфліктує з прокруткою (`touch-action: none` лише на блоках; стрічка палітри гортається по горизонталі), числа вводяться кнопками −/+ без екранної клавіатури.
- **Масштаб і розкладка**: без горизонтального скролу на 360–414 px, текст масштабується (rem).
- Мова сторінки `lang="uk"`, skip-link, семантичні регіони (`main`, `section`, `aside`, `nav`).

## Не перевірено

Екранні читачі (NVDA, VoiceOver, TalkBack) на реальних пристроях; режим високого контрасту Windows поза `prefers-contrast: more`.

## Правила для змін

1. Нова взаємодія — з клавіатурною альтернативою й оголошенням для читача екрана.
2. Нова модалка — `role="dialog" aria-modal`, `trapFocus`, додати id в `MODAL_OVERLAY_IDS` (`main.js`), повернення фокуса.
3. Нові кольори тексту — токени в `tokens.css` і рядок у `TEXT_PAIRS` тесту контрасту.
4. `touch-action: none` лише на `.blk` (тест).
5. Не покладатися лише на колір: стан блока (виконується, помилка) має ще й товщину/пунктир контуру.
